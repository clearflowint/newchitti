# ClearFlow SaaS Multi-Tenant NocoDB Architecture Specification

This document details the complete relational schema design for hosting multi-tenant Chit Fund ("Chitti") circles on a shared NocoDB base.

---

## Multi-Tenant Security & Isolation Principles

1. **Native UUID as `Global_ID`**:
   - Every entity generated by the backend API server is assigned a standard UUID v4 (`Global_ID`).
   - NocoDB's internal auto-increment integer IDs (`Id`) are ignored by business logic.
   - Any retry or re-queued job uses the existing `Global_ID`, providing 100% idempotent `PATCH` upserts without duplicate rows.

2. **Tenant Partitioning (`Tenant_ID`)**:
   - Every table stores `Tenant_ID` (e.g. `TNT-840192`).
   - The backend API proxy automatically injects `where=(Tenant_ID,eq,[Tenant_ID])` on every read and write.
   - Cross-tenant data leakage is cryptographically and logically prohibited.

3. **Rate Limiting & Shock Absorption (5 Req/Sec Rule)**:
   - NocoDB enforces a strict limit of 5 requests per second.
   - The custom backend incorporates an in-memory queue (`OutboxQueue`) and a rate-throttled worker running at **max 4 requests per second** (250ms spacing).
   - Incoming mutations return HTTP `202 Accepted` immediately, eliminating user-facing latency and buffering traffic spikes safely.

## Database Tables & Column Specifications

### 1. `Tenants` Table
Represents chit fund operator tenant accounts.

| Column Name | Type | Constraints | Description |
|---|---|---|---|
| `Global_ID` | UUID / String(36) | Primary Unique | Universal UUID |
| `Tenant_ID` | SingleLineText(32) | Unique, Index | Tenant partition code (e.g., `TNT-840192`) |
| `Company_Name` | SingleLineText(128) | Required | Operator or Agency Name |
| `Manager_ID` | SingleLineText(6) | Unique, Index | 6-digit non-reusable manager code |
| `Email` | Email | Required | Manager Email |
| `Phone` | PhoneNumber | Required | Manager Mobile |
| `Status` | SingleSelect | 'Active', 'Suspended', 'Trial' | Account status |
| `Created_At` | DateTime | Auto | Record creation timestamp |
| `Updated_At` | DateTime | Auto | Last update timestamp |

### 2. `Chitti_Groups` Table
Represents individual community chit savings circles.

| Column Name | Type | Constraints | Description |
|---|---|---|---|
| `Global_ID` | UUID / String(36) | Primary Unique | Universal record UUID |
| `Tenant_ID` | SingleLineText(32) | Index, Foreign Key | Partition FK to `Tenants` |
| `Chitti_ID` | SingleLineText(6) | Index | 6-digit non-reusable circle identifier |
| `Manager_ID` | SingleLineText(6) | Required | 6-digit manager code |
| `Chitti_Name` | SingleLineText(128) | Required | Circle title (e.g. 'Mahalakshmi Chits') |
| `Rule_Template` | SingleLineText(64) | Default 'Incremental Model V1' | Calculation formula engine |
| `Total_Members` | Number (Integer) | Required | Total share slots $S$ (e.g., 20) |
| `Total_Months` | Number (Integer) | Required | Duration $M$ (e.g., 20) |
| `Undrawn_Due` | Decimal(12,2) | Required | $D_{\text{undrawn}}$ installment amount |
| `Drawn_Due` | Decimal(12,2) | Required | $D_{\text{drawn}}$ installment amount |
| `Monthly_Commission` | Decimal(12,2) | Required | Foreman monthly commission $C$ |
| `Current_Month` | Number (Integer) | Default 1 | Active monthly cycle number (1..$M$) |
| `Cycle_Start_Date` | Date | Required | Anchor start date |
| `Cycle_Anchor_Day` | Number (Integer) | Default 10 | Day of the month for collection |
| `Frequency` | SingleSelect | 'Monthly' | Auction frequency |
| `Status` | SingleSelect | 'Active', 'Completed', 'Draft' | Circle lifecycle status |
| `Created_At` | DateTime | Auto | Record creation timestamp |
| `Updated_At` | DateTime | Auto | Last update timestamp |

### 3. `Shares` Table
Represents individual member shares within a circle.

| Column Name | Type | Constraints | Description |
|---|---|---|---|
| `Global_ID` | UUID / String(36) | Primary Unique | Universal record UUID |
| `Tenant_ID` | SingleLineText(32) | Index | Partition FK to `Tenants` |
| `Chitti_ID` | SingleLineText(6) | Index | Foreign Key to `Chitti_Groups` |
| `Share_ID` | SingleLineText(6) | Index | 6-digit non-reusable unique share code |
| `Share_Number` | Number (Integer) | Required | Roster sequence $1..S$ |
| `Member_Name` | SingleLineText(128) | Required | Member full name |
| `Phone_Number` | PhoneNumber | Required | Member mobile number |
| `Draw_Status` | SingleSelect | 'Undrawn', 'Drawn' | Current prizing status |
| `Month_Drawn` | Number (Integer) | Nullable | Month the share won auction |
| `Advance_Credit` | Decimal(12,2) | Default 0.00 | Excess payment reserve |
| `Created_At` | DateTime | Auto | Record creation timestamp |
| `Updated_At` | DateTime | Auto | Last update timestamp |

### 4. `Chitti_Cycles` Table
Represents monthly cycle reconciliation and auction results.

| Column Name | Type | Constraints | Description |
|---|---|---|---|
| `Global_ID` | UUID / String(36) | Primary Unique | Universal record UUID |
| `Tenant_ID` | SingleLineText(32) | Index | Partition FK to `Tenants` |
| `Chitti_ID` | SingleLineText(6) | Index | Foreign Key to `Chitti_Groups` |
| `Month_Number` | Number (Integer) | Required | Cycle month $m$ (1..$M$) |
| `Gross_Pool` | Decimal(12,2) | Required | $P(m) = n_u D_{\text{undrawn}} + n_d D_{\text{drawn}}$ |
| `Monthly_Commission` | Decimal(12,2) | Required | Foreman commission $C$ |
| `Net_Payout` | Decimal(12,2) | Required | $W(m) = P(m) - C$ |
| `Winner_Share_ID` | SingleLineText(6) | Nullable | 6-digit Share ID of auction winner |
| `Status` | SingleSelect | 'Scheduled', 'Active', 'Reconciled' | Cycle status |
| `Reconciled_At` | DateTime | Nullable | Reconciliation timestamp |
| `Created_At` | DateTime | Auto | Record creation timestamp |

### 5. `Transactions` Table
Represents member installment payment ledger records.

| Column Name | Type | Constraints | Description |
|---|---|---|---|
| `Global_ID` | UUID / String(36) | Primary Unique | Universal record UUID |
| `Tenant_ID` | SingleLineText(32) | Index | Partition FK to `Tenants` |
| `Chitti_ID` | SingleLineText(6) | Index | Foreign Key to `Chitti_Groups` |
| `Trans_ID` | SingleLineText(64) | Index | Logical identifier (`{Chitti_ID}_M{m}_{Share_ID}`) |
| `Share_ID` | SingleLineText(6) | Index | Foreign Key to `Shares` |
| `Month_Number` | Number (Integer) | Required | Installment cycle month |
| `Draw_Status` | SingleSelect | 'Drawn', 'Undrawn' | Status at the time of calculation |
| `Amount_Due` | Decimal(12,2) | Required | Calculated due for this share/month |
| `Amount_Paid` | Decimal(12,2) | Default 0.00 | Amount collected |
| `Pending_Dues` | Decimal(12,2) | Default 0.00 | $\max(0, \text{Due} - \text{Paid})$ |
| `Payment_Status` | SingleSelect | 'Verified', 'Partial', 'Pending' | Payment verification |
| `Payment_Mode` | SingleSelect | 'UPI', 'Cash', 'Advance Credit', 'Bank Transfer' | Mode of settlement |
| `Payment_Date` | Date | Nullable | Payment collection date |
| `Payment_Ref` | SingleLineText(64) | Nullable | Bank/UPI reference number |
| `Entry_Type` | SingleSelect | 'Credit', 'Debit' | Ledger adjustment type |
| `Created_At` | DateTime | Auto | Record creation timestamp |
| `Updated_At` | DateTime | Auto | Last update timestamp |

### 6. `Outbox_Jobs` Table
Buffer queue and audit log of rate-limited mutations sent to NocoDB.

| Column Name | Type | Constraints | Description |
|---|---|---|---|
| `Job_ID` | SingleLineText(64) | Primary Unique | Unique Job Identifier |
| `Tenant_ID` | SingleLineText(32) | Index | Partition FK to `Tenants` |
| `Global_ID` | UUID / String(36) | Index | Entity Global UUID |
| `Entity_Type` | SingleLineText(64) | Required | Target table name |
| `Operation` | SingleSelect | 'CREATE_CHITTI', 'CREATE_SHARES', 'RECORD_PAYMENT', 'UPDATE_DRAW', 'UPDATE_CONTACT', 'DELETE_CHITTI' | Write operation type |
| `Payload` | JSON / LongText | Required | Serialized mutation payload |
| `Status` | SingleSelect | 'QUEUED', 'PROCESSING', 'COMPLETED', 'FAILED' | Execution state |
| `Attempts` | Number (Integer) | Default 0 | Retry counter |
| `Error_Message` | LongText | Nullable | Failure diagnostics |
| `Created_At` | DateTime | Auto | Job dispatch timestamp |
| `Processed_At` | DateTime | Nullable | Worker execution timestamp |
